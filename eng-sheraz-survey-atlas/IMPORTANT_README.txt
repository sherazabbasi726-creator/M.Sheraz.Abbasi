ENG SHERAZ SURVEY ATLAS — RELEASE CANDIDATE (22 Nov 2026)

INSTALL: Upload the CONTENTS of this folder into a NEW GitHub Pages folder such as eng-sheraz-survey-atlas/ (not the old alomaier.html). Open https://<username>.github.io/<repository>/eng-sheraz-survey-atlas/ .

The Atlas map/IFC reference data opens immediately from alomaier-source.json. Engineering Workspace automatically creates the Alomaier project and starts importing IFC points into browser IndexedDB on first opening. This can take minutes on a mobile device. Keep the page open until the status confirms completion. If interrupted, reopen the workspace to resume using stable IDs. Local survey edits are device-specific; export JSON backups regularly. Do not clear browser data before backing up.

IMPORTANT: This is a release candidate, NOT a field-certified final. Browser UI, full mobile offline operation, and quantity accuracy for real site measurements have not been independently validated. Source historical WIRs are unverified; IFC point numbers are generated references. Point cut/fill classification is not a certified volume. The site map is a project-grid SVG, not a satellite map. The engineering workspace is embedded in the unified Atlas shell and retains some legacy layouts.
