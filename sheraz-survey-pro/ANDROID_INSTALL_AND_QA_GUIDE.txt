DEPLOY TO GITHUB PAGES
1. Extract ZIP and upload ALL contents of the sheraz-survey-pro folder to the repository root (the folder's files, not the ZIP).
2. In GitHub repository Settings > Pages, publish from the branch and folder holding index.html.
3. Wait for deployment; open the published HTTPS URL in Chrome on Android.
4. Open Chrome menu > Add to Home screen > Install app (wording varies). Some devices will show an Install App button in the header.
5. For an existing installation, reload while online to receive updated assets. If outdated, close and reopen the app.

OFFLINE SMOKE TEST
